# Next Cue

Next Cue is an ADHD routine starter: it breaks routines into small steps and shrinks a step to one tiny first move when you are stuck.

Generate the Xcode project with `xcodegen generate`. StoreKit testing is configured in the `NextCue` scheme through `NextCue.storekit`.

See `AGENTS.md` for app identifiers and `.claude/rules/store-and-release.md` for store setup.
